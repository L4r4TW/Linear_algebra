Exercise sources and credits

Practice problems come from the WeBWorK Open Problem Library. Author and institution credits appear on exercise cards. Where the source does not name an author, we retain the available institutional credit.

The library's default content license is Creative Commons Attribution–NonCommercial–ShareAlike 3.0, unless an individual contribution provides another notice. See the license notice for this library snapshot.

This installation is a local, noncommercial development pilot. Original problem sources are unchanged; catalog titles may be edited for clarity. Commercial or public deployment needs a separate rights and deployment review.

WeBWorK, PG, and their software dependencies retain their separate software licenses. No contributor endorsement is implied.
